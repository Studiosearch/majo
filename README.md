# Majo — Landing page

Landing page estática (HTML + CSS + JS puro, sem build) do estúdio **Creative Majo**.

## Estrutura
- `index.html` — página completa
- `assets/` — fotos, símbolo e pattern
- `assets/fonts/` — coloque aqui a fonte de título **Moraine Parnley Regular**
  como `MoraineParnley-Regular.woff2` (ou `.otf` / `.ttf`). Sem o arquivo, a página usa a fonte reserva (Caveat).

## Publicar no GitHub Pages
1. Suba os arquivos na raiz do repositório.
2. Em **Settings → Pages**, escolha *Deploy from a branch* → branch `main` → pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
